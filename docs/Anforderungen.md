# Anforderungen

1. Der Nutzer muss grundlegende Parameter zu seinem Gebäude eingeben können. 
2. Das System muss unlogische Kombinationen erkennen und den Nutzer darauf hinweisen. 
3. Das System berechnet auf Basis der Eingaben automatisch eine Kostenspanne.
4. Nach Absenden des Formulars erhält die Firma automatisch eine E-Mail, dass ein neuer Lead eingegangen ist. 
5. Leads sollen in einer Verwaltungssoftware angezeigt und gemanagt werden.
6. Die Kostenschätzung soll ein Richtwert sein und keine verbindliche Feinplannung.

# NFA (Nicht funktionale Anforderungen)

1. Die Web-App soll auf verschiedenen Geräten funktionieren (Smartphone, Tablet, Laptop)
2. Der Konfigurator muss als intuitiver Step by Step Assisent aufgebaut sein.
3. Seitenwechsel innerhalb des Konfigurators müssen innerhalb 1. Sekunde laden.
4. Die Berechnung der Kostenschätzung muss ohne spürbare Verzögerung erfolgen.
5. Personenbezogene Daten müssen verschlüsselt in der Datenbank gespeichert werden.
