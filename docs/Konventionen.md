# SYP Projekt Konventionen

## Sprache
Begriffe wie Endkunde, Kunde und Auftraggeber (AG) sind in `Glossar.md` festgelegt.

## Allgemein
Als Textformat verwenden wir Markdown
Filenamen mit Unterstrich "_" trennen

## GitHub
Alle Commit-Messages erfolgen auf Deutsch.
Für jede Programmier-Issue wird ein neuer Branch erstellt
Branches werden von einer anderen Person gemerged als der, die sie implementiert hat

## Repositories
- Dokumente werden im Git-Repository im "docs" Ordner gespeichert
- Code wird im Git-Repository im "src" Ordner gespeichert.
