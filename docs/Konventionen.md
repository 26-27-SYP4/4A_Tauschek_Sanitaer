# SYP Projekt Konventionen

## Sprache
Endkunde: Der Kunde unseres Kunden  
Auftraggeber(AG): Geschäftsführer der Tauschek GmbH

## Allgemein
Als Textformat verwenden wir Markdown
Filenamen mit Unterstrich "_" trennen

## Github
Alle commit messages erfolgen auf Deutsch.  
Bevor etwas gepusht wird/branches auf main gemerged werden, muss es von jemand anderem überprüft werden.

## Repositories
- Dokumente werden im Git-Repository im "docs" Ordner gespeichert
- Code Verwaltung erfolgt über Git-Repository im "src" Ordner gespeichert.
