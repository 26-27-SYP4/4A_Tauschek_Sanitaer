# Arbeiten mit KI

- Große Aufgaben in kleinere, überschaubaren Schritte zerlegen.
- Regeln Festlegen: Explizit erwähnen was die KI einhalten soll.
- Code überprüfen, nicht einfach von der KI copy-pasten

## Verwendete KIs
- Claude Code
- Gemini Pro 
- ChatGPT Go.

## Für die Skills:
- Rollen-Definition: "Du bist ein Senior Frontend-Architekt, der auf barrierefreie, performante Multi-Step-Formulare und schlanke Web-Architekturen spezialisiert ist."

## Architektur-Regeln: 
- UI-Darstellung und Berechnungslogik strikt trennen. Die Rechenfunktionen müssen als reine Funktionen ("Pure Functions") isoliert bleiben, damit sie automatisiert getestet werden können.
